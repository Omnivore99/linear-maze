Linear Maze Editor

Open the game folder to manage its floors, maps, items, monsters, tile sets and the player. Changes are saved into the folder as an editor pack, so the original pack files stay as they are.

Pick the folder that holds index.html, engine and packs (for example linear-maze-0.3). The browser asks once for permission to edit files in it. Works in Chrome and Edge.

  • Floors in order: drag, remove, duplicate, add.
  • Maps painted with the floor’s own tiles, items, monsters and people, lit as in the game.
  • Items and everything they do, from an altar’s blessings to a slot machine’s paytable.
  • Monsters, their attacks, drops and looks, with picture import and image prompts.
  • The player at the start of a run, and tile sets for new materials and moods.
  • Claude can make or change any of these from a description.

This browser can’t save into folders. Use Chrome or Edge for the full editor, or open the folder read-only here and download the changed files when you save.
